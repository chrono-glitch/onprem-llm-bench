# PURPOSE

## Why this repo exists

Dante is a 7-year business/BI analyst who taught himself to ship production AI
(a multi-agent WhatsApp system; a predictive model at a bank that replaced a
vendor), now independent. Next step: level up into a defensible position —
either a strong **AI-infrastructure / Solutions-Architect role**, or **his own
product** for LATAM SMBs.

Both need the same thing: **one finished, public, credible artifact** that shows
he can architect and ship AI infrastructure. Consulting work isn't visible. A
dropped CS degree is a story to override. A repo + a writeup + a presence speaks
for itself.

## What this specific project delivers toward that

- **Proof** of AI-infrastructure capability (his CV's actual grain: Docker,
  Linux, on-prem inference, edge, distributed systems).
- **Visible** — a GitHub repo + a bilingual writeup recruiters and clients can read.
- **Option-preserving** — serves a job pivot *or* a product; no need to choose yet.
- **Differentiated** — serving LLMs on-prem, no GPU, framed for the
  Spanish-speaking mid-market. Almost nobody covers this well.

## The meta-purpose

**Finish one thing.** The project is a vehicle; any of a few good options would
serve. The missing skill — made obvious over a session of ~16 direction changes —
is completion. That's the gap that unlocks the rest.

Success for the next 10 working days = still working on this, with a repo he can
send someone.
